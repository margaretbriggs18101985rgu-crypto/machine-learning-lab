# 机器学习课程实验

这是一个 Codex 技能，用于按课程模板完成机器学习、数据分析和 Python 实验。它指导 Codex 使用给定数据运行 Notebook，核对图表和指标，并按要求提交报告与真实运行截图。

## 安装

从 GitHub 仓库页面复制克隆地址，将仓库克隆到 Codex 技能目录中的 `machine-learning-lab` 文件夹。默认位置为 `~/.codex/skills/machine-learning-lab`。如果设置了 `CODEX_HOME`，请使用 `$CODEX_HOME/skills/machine-learning-lab`。安装后，在 Codex 中打开实验工作区。

## 使用

将实验模板、数据和相关课件放进工作区，然后向 Codex 指定实验目录和交付要求。

> 用 $machine-learning-lab 完成实验三。严格按 Word 模板提交，使用相对路径读取数据，并保留真实运行截图。

[技能说明](SKILL.md)介绍完整流程，[Jupyter 运行与截图](references/jupyter-capture.md)说明如何保存真实执行结果和采集截图。
