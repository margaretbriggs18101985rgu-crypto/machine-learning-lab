# Jupyter 运行与截图

1. 优先复用可访问的 Jupyter 实例和实验内核。需要新开服务时，绑定本机回环地址，将服务根限制在实验目录，使用可用端口和正常认证。凭证仅在本地会话中传递，避免进入日志、截图和交付文件。核对当前内核能导入依赖，且工作目录能解析 Notebook 中的相对路径。
2. 保存最终代码后，在 Jupyter 界面重启内核并运行全部单元。自动化按界面当前语言定位菜单和确认框。菜单保持展开时，可先移动指针再点击。目标单元尚未渲染时，滚动到该单元。以末个目标输出出现、图像加载和内核空闲判断完成，再保存并从磁盘核对执行编号、所需输出及错误。
3. 从实际界面截取模板指定的区域。模板允许时可只截相关单元格，保留执行编号、关键代码和输出，以便嵌入报告后仍然可读。逐张查验汉字、坐标轴、图例和指标。重新生成相关结果后，使用与最终运行对应的截图。
4. 界面无法启动内核运行时，可用 `nbclient` 或 `nbconvert --execute` 在可用的本地内核中从正确目录执行并保存，再在 Notebook 界面打开已保存的运行结果并实际截屏。说明执行和截图各自使用的方式。没有可用截图界面时，交付可验证的运行结果并明确截图缺项。导出的绘图图片、合成界面和旧截图均不能代替本次所需的界面截图。
